# 诗境 Poetry Realm · 标签体系方案 v1

> 目标：让「文体」等标签像专题一样，在诗词库 / 详情页 / 首页 / 画廊 / 专题各处统一可见、可点、可筛。
> 策略：**准确优先** —— 只对可精确判定的作品打 L1 标签，不靠启发式硬猜（全唐诗库普通作品暂只标大类「诗」）。

## 一、标签维度（三层，可叠加显示）

| 维度 | 说明 | 状态 |
|---|---|---|
| **L1 · 文体** | 五绝 / 七绝 / 五律 / 七律 / 五古 / 七古 / 乐府 / 宋词·小令 / 宋词·中调 / 宋词·长调 / 诗经 / 楚辞 | 本期新增（主推 chips） |
| **L2 · 选本专题** | 唐诗三百首 / 宋词三百首 | 已上线（tags.json + 专题页 + 部分徽章） |
| **L3 · 主题**（二期） | 山水田园 / 边塞 / 送别 / 怀古咏史 / 思乡 / 爱情 / 咏物 / 闲适 / 豪放 / 婉约 / 元宵 / 中秋 … | 语义判定，需 NLP/批量归纳，暂缓 |

## 二、L1 精确判定来源（准确优先）

1. **《唐诗三百首》卷次 = 权威体裁**（蘅塘退士按诗体分卷），318 篇全部精确打标：
   - 卷一：五言古诗、五言乐府
   - 卷二：七言古诗、七言乐府
   - 卷三：五言律诗
   - 卷四：七言律诗、七言乐府（独不见）
   - 卷五：五言绝句、五言乐府
   - 卷六：七言绝句、七言乐府
2. **《宋词三百首》+ 全库宋词**：按词作字数精确分调（去标点汉字计数）：
   - 小令 ≤ 58 字（如梦令/忆江南/长相思/生查子…）
   - 中调 59–90 字（蝶恋花/青玉案/鹧鸪天/踏莎行…）
   - 长调 > 90 字（水调歌头/念奴娇/满江红/八声甘州/兰陵王…）
   - 另保留「宋词」大类标签
3. **已生成沉浸页**（11 篇 + 未来）：随其源诗（三百首/宋词/其他库内诗）打同款 L1。
4. 诗经（四言为主）、楚辞（骚体）：按库内已标 genre 直接归类，数量少（诗经 305 / 楚辞 65），打大类标签。
5. 全唐诗库其余 6 万+：不推断近体（律/绝 vs 古体需平仄校验，启发式会误标）→ 只给「诗」大类；后续若要细分，用平水韵校验工具二次处理。

## 四、数据与实现

- **存储**：新增 `data/poem_tags.json`（或并入 ranking.db 加 tag 表）：`{ db_id: { genre: '七言绝句', …tags: [] } }`
  - 派生脚本：从 `tangshi300.txt` 卷标 + `ranking.db`(宋词 source 与字数) + `poems.genre` 一键生成
  - 与 L2 选本并列：展示端 `[七言绝句] [唐诗三百首·第 N 位]` 双 chip
- **接口**：`GET /api/tags/:dbId`（详情）、`GET /api/tags-map`（批量，供列表页一次拉取）
- **前端 chips**：统一小徽章（金银双色区分文体/选本）；接入位置：
  - 诗词库卡片
  - 详情页 hero
  - 首页命运卡
  - 首页 AI 沉浸卡
  - 沉浸画廊卡片
  - 专题页
- **筛选**：诗词库/画廊按 L1 文体筛选 chips（仿诗人筛选）

## 五、实施步骤
1. `build-tags.py`：生成 `poem_tags`（三百首卷标 + 宋词字数 + genre）→ 校验统计
2. server 接口 2 个
3. 前端 `<TagChips>` 组件 + 6 处接入
4. 诗词库按文体筛选
5. 构建 / 验证 / 提交同步
