# 视频方向规范（video-direction）

把一首已制作完的 AI 沉浸页（画面 + 逐段解读）进一步生成**逐画面短视频**时的提示词与实现规则。
运行时模板与 `web-system/scripts/generate-video.mjs` 同源（本文件为准，脚本实现保持一致）。

## 产品形态

一首诗 = 多个画面段（hero + scene-N），**一个画面生成一段短视频**。
默认图生视频；如给某诗选择「虚拟人像」出演（`--avatar asset-xxxx`），人物由火山方舟官方虚拟人像库资产演绎——不涉及真人肖像合规。

## 视频内提示词模板（两处关键约束）

1. **诗句字幕走前端叠加，不渲染进画面**。与生图同一规则：模型画面内不得出现任何文字/字幕/书法/水印；
   构图必须**在右侧或下部保留暗色负空间**，供前端竖排诗句覆盖（文字永远清晰、可复制、可随字体切换，不会乱字）。
2. **台词口播**（仅虚拟人像模式）：要求人物用中文清晰缓慢、字正腔圆地朗诵该句诗句，口型同步。
   台词与画面指令分节（`【台词】…` / `【画面】…`），避免把画面指令当台词念出。

模板（虚拟人像模式）：

```
【台词】请用中文清晰、缓慢、字正腔圆地朗诵以下诗句，口型与吐字同步："<诗句>"。
【画面】写实电影感古风画面呈现该句意境；画面内不出现任何文字、字幕、书法或水印标记；
构图人物与主体居中偏左或留景，画面右侧或下部保留暗色负空间，便于前端叠加竖排诗句字幕；
克制水墨调色、真实历史质感。
```

图生视频模式：`<诗句>。画面内不出现任何文字…；右侧或下部保留暗色负空间…（同上约束）`

## Seedance 参数

| 参数 | 取值 | 说明 |
|---|---|---|
| model | doubao-seedance-2-0-mini-260615 | 视频模型（env ARK_MODEL 可改） |
| reference_images / use_virtual_avatar | `["asset://asset-xxxx"]` / `true` | 虚拟人像模式（人物官方形象，绕开真人拦截） |
| ratio | 16:9 | 与页面一致 |
| duration | 11（页面按钮）；实验可 5 | 秒 |
| generate_audio | true | 虚拟人像会生成人声旁白 |
| watermark | false | 页面素材免平台水印 |

## 前端叠加（播放层）

- 每段视频上方叠**竖排诗句**（`writing-mode: vertical-rl`，诗体字体 poem-text，右侧暗部负空间位置，带描边阴影保证可读），不拦截 video controls。
- 诗句来自该段 `original`（纯原句，不含提示词模板标签）。
- 人声来源：虚拟人像模式自带口播；如需稳定音轨可叠加该诗已有朗诵 mp3（data 生成包 audio.voices[].scenes）做复读/配音。

## 校验清单（QA）

- [ ] 单段 ≤ 成片时长内台词清晰（抽查 whisper/人工听）
- [ ] 画面内无乱字（有字 → 应属生成失败，前端字幕正确显示即达标）
- [ ] 右侧/下部负空间足够，前端竖排诗句可读且不遮主体
- [ ] 形象一致：同一首诗多段若用同一 asset，人物形象稳定
- [ ] 虚拟人像模式不触发「real person」拦截；图生视频人物图注意构图远景/无正脸
- [ ] mp4 可播（H.264+AAC，1280×720 或等效）
